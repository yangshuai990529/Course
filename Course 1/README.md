# UIUX-Industry-Lesson

Lesson 00：数字产品设计行业认知。Apple Keynote 风格的 16:9 交互课件，共 27 个教学场景，六章建议时长为 15、25、20、20、25、15 分钟，合计 120 分钟。面向有平面设计基础的本科生，适合腾讯会议 1 对 1 授课。

## 直接使用

双击本目录 `index.html`，在 Mac Safari 或 Chrome 中打开。不需要安装依赖或联网。根目录与 `dist/index.html` 为相同的离线单文件，React、Framer Motion、样式及内容均已内联，不使用 CDN、在线字体、远程图片或接口。整个文件约 453 KB。

- 左右方向键、Page Up / Page Down：翻页。
- 空格：下一页；按钮和输入框获得焦点时保留原生操作。
- Home / End：封面 / 最后一页。
- D：章节导航，支持跳到任意页。
- N：讲师备注。
- F：进入 / 退出全屏。
- Esc：关闭章节和备注，浏览器可退出全屏。

输入框、选择框和文本区域中的按键不会触发翻页。交互控件支持可见键盘焦点。画布以 1600×900 编排，按视口等比缩放；1920×1080 和 2560×1440 均保持 16:9，其他比例留黑边。

备注显示在当前屏幕中，**腾讯会议共享时需要关闭**。可在另一台设备查看 `讲师备注.md`，其中每页包含目标、讲解话术、案例、提问、互动、预计时间、常见疑问与总结。`课堂练习.md` 包含练习任务、参考要点和讲师评价标准。

Agent 演示需要先批准计划，再逐步执行。取消和人工接管会停止后续步骤，已完成步骤不会被自动撤回；完成后显示订单结果。CUI 使用确定性澄清规则，并未接入 AI 模型。

最后一页的分析默认只保存在浏览器本地，不发送到服务器。如浏览器不允许本地存储，页面提示下载文本。换浏览器、换文件路径或清理浏览器数据可能影响草稿保留，请在授课结束时下载。完整度检查仅检查填写情况，内容质量由讲师评价。

## 案例与证据边界

所有产品界面、品牌、商品、企业订单、政务流程和账号均为原创教学模拟。没有真实付款、身份认证、后台审核、医疗诊断或真实 AI 调用。企业界面权限只演示前端交互，真实系统必须由服务端校验。

第 19 页全部数字均为合成教学数据。前后各 20 人的任务完成率为 12/20 与 17/20，提升 25 个百分点。耗时为成功者中位数。业务吞吐示例单列口径，不能直接推出因果关系。

没有引用未经验证的就业、薪资、行业规模或 AI 采用率数据。AI 能力、趋势观察与未来预测分别呈现。24 小时课程仅为入门实践建议，不承诺就业。岗位边界因公司、地区与业务而异。公共服务、汽车和医疗示例不构成实际政策、安全标准或合规结论。

用户提供的两张图作为课程补充主题来源：硬件与软件结合的设计、GUI/CUI/Agent 三种交互形态。课件使用重新制作的离线模拟，不引用图中无法核实来源的界面缩略图。

## 修改与构建

技术栈：React 19、TypeScript、Vite 7、Tailwind CSS 4、Framer Motion 12。系统字体，纯本地界面。

```sh
npm ci
npm run dev
```

开发入口为 `http://127.0.0.1:5173/dev.html`，`dev.html` 与生成后的 `index.html` 分开，避免源码入口被构建结果覆盖。

```sh
npm run build
node scripts/notes.mjs
```

构建先执行 TypeScript 检查，再通过 Vite 打包，`scripts/inline.mjs` 将 JS/CSS 内联到根目录及 `dist/index.html`。备注脚本从课程数据导出 Markdown。运行单文件不需要 `node_modules`，开发构建需要 Node.js 20.19+ 或 22.12+。

- `src/course.ts`：27 页内容、备注、岗位、流程与学习路线。
- `src/main.tsx`：教学交互、导航、全屏、练习保存。
- `src/style.css`：16:9 布局、主题、产品模拟界面。
- `scripts/qa.mjs`：离线 Chrome 验证脚本，需要本机安装 Chrome。
